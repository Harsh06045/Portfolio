# Harsh Kumar - Modern 3D Portfolio

An interactive, high-performance developer portfolio built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## ✨ Features

- **3D Hero Section**: Interactive 3D cutout portrait with cursor-tracking magnetic physics and metallic typographic styling.
- **Dynamic Project Showcase**: Sticky stacked cards showcasing real-world projects:
  - **BloodCare**: Full-stack healthcare portal with blood donation hubs, donor verification, and urgent SOS alerts.
  - **EduLearn Pro**: Scalable learning management platform with modern dashboards and responsive UI.
  - **Credentials Card**: Fast access to verified technical skills, certifications, and experience.
- **Resume-Driven Interactive Showcase**: Scroll-synced interactive showcase featuring live code demos, clean architecture, and technical stacks.
- **Fluid Micro-Animations**: Smooth scroll reveal transitions, interactive live project modals, and magnetic buttons powered by Framer Motion.
- **Glassmorphic Design System**: Sleek dark aesthetic (`#0A0B0E`), bespoke border glows, and responsive typography.

## 🚀 Tech Stack

- **Framework**: React 19 + Vite 8
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom CSS Utilities
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Harsh06045/Portfolio.git

# Navigate to the project directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
